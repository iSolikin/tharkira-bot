# Tharkira Bot

Автоматизирует игровой цикл в Tharkira, пока открыта вкладка: повторные бои, развитие героев и работу с экипировкой.

### Что внутри

- Выбирает следующий этап с учётом побед и поражений.
- Прокачивает характеристики, навыки и таланты по плану для каждого героя.
- Подбирает экипировку и открывает сундуки, когда есть место.
- Следит за состоянием вкладки и сообщает, если нужно ваше участие.

Авторизация через Google остаётся за вами.
