# Tharkira Bot

**Помощник для повторяющихся действий в Tharkira.** Расширение Chrome работает в открытой вкладке игры.

## Возможности

- Ведёт повторяющиеся бои и подбирает следующий этап с учётом результатов.
- Развивает героев по плану: характеристики, навыки, таланты и экипировку.
- Открывает сундуки при наличии места в инвентаре.
- Следит за вкладкой и уведомляет, когда нужно действие человека.

Вход через Google выполняет пользователь; бот не авторизуется вместо него.
